## 👋 About me

- 🎮 Indie game developer and designer based in **Istanbul, Turkey**
- 🧩 Co-founder of **[Zero Task](https://www.zerotaskstudios.com/)** ([GitHub](https://github.com/Zero-Task-Studios)), an indie game studio. I work on programming, game design, narrative and the business side of our games
- ✍️ I like building games around story and systems. I created **808** (story, level design, development) and led the team behind **Live Corp** as project manager and lead developer
- 🎓 Computer Engineering graduate (FMV Işık University, 2025) · Trained at **42 Istanbul** · Graduate of **Google Game and Application Academy**
- 🔭 Currently working on **Shake it Co!** and **Terminidle** (releasing Nov 3, 2026)
- 💼 **Open to game developer roles**: let's talk!
